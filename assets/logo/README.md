# Robust Warehouse — Logo

Pure-vector SVG marks. The icon contains no text or fonts, so it renders identically everywhere.

| File | Use |
| --- | --- |
| `icon.svg` | App icon / avatar / product mark (64×64) |
| `favicon.svg` | Browser favicon (tighter glyph for small sizes) |
| `logo-horizontal.svg` | Header, invoices, email signatures |
| `logo-wordmark.svg` | Text-only lockup |
| `logo-mono.svg` | Single-color print / emboss / favicon fallback (uses `currentColor`) |

## Colors

| Token | Hex | Use |
| --- | --- | --- |
| Navy | `#0E2E4A` | Badge, primary text |
| Amber | `#F2A007` | Crate accent, secondary text |
| White | `#FFFFFF` | Glyph on badge |

## Notes

- The mark is a geometric **R** whose counter is an amber crate.
- The wordmark uses `Arial, Helvetica, sans-serif`. Convert text to outlines before sending to print vendors.
- Minimum size for the icon: 24×24 px. Below that use `favicon.svg`.
